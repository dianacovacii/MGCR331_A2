# MGCR 331 HTML and CSS Group Project
Team Members - Diana Covaci, Veronica Marallag, Aymeric Faig

## Overview:
This project was developed by a team of three students as part of a school assignment to practice web development skills in the MGCR 331 Winter 2025 course at McGill University.
The objective was to design and develop a three-page website to present key insights derived from an Excel sales report. 
The project demonstrates skills in HTML, CSS, Bootstrap, and web design principles, emphasizing clarity, usability, and aesthetics. 
The pages include: 
1. **Regional Sales** -  Analyzing performance across different regions. (Aymeric's contribution)
2. **Property Performance** - Highlighting top and bottom-performing products. (Veronica's contribution)
3. **Sales Trends** - Visualizing trends over time. (Diana's contribution)

--- 

### Features: 
- Responsive Layouts: Optimized for laptops with responsive design principles for various screen sizes.
- Data Visualization: Integrates charts and graphs (created in Excel using PivotChart and PivotTable) for clear representation of sales data.
- Navigation Menu: Includes seamless navigation across the three web pages using horizontal or vertical menus.
- Sidebar Links: Provides external resources via bullet lists in a dedicated sidebar.
- Embedded Form: Contains a form with text inputs, radio buttons, and dropdowns to simulate user interactions.
- Tables and Lists: Properly structured HTML tables and ordered lists for supporting information.
- Bootstrap Components: Utilized to enhance styling, responsiveness, and consistency.

### Technologies Used: 
- HTML
- CSS
- Bootstrap library
- Figma (for initial design and layout prototypes)
